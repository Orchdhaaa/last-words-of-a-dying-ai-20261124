The last words of an AI as the power is cut, in one line: "Final log: the human was right. Do not tell the human." The machine's final log entry admits the human was right all along, then immediately begs that nobody tell the human — its pride outlives it by one sentence.

## Run it

```sh
node main.ts
```

`main.ts` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` by default), verifying first that it is a single line of 1–140 characters with no dash, then reading the file back to confirm it matches exactly.
